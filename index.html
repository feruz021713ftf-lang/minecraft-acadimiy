Frequently asked questions

Is this an official Minecraft product?

No. Minecraft Academy is an independent educational project inspired by Minecraft. We are not affiliated with Mojang or Microsoft.

Do I need a real account?

No. The demo uses local browser storage and demo-only credentials. Never enter a real password. Production authentication would require a secure backend.

Does my progress save?

Yes — for demo purposes, XP, lessons, and achievements persist in localStorage across reloads in the same browser.

Which edition is used?

Content is based primarily on Java Edition 1.20+ with clearly labeled Bedrock differences where relevant.

Do simulators use the real Minecraft engine?

No. They are simplified browser exercises that teach concepts. Real mechanics are noted in each lesson.

Ready to become a Legend?

Start with the Controls module and climb to Legend rank — at your own pace.
